# Модуль для импортирования банковских выписок
### форк [этого модуля](https://apps.odoo.com/apps/modules/17.0/import_bank_statement_odoo)

Пока что только работает на выписках формата TXT и SWIFT от Паритетбанка.
## Функционал модуля
- парсировка выписок по транзакциям
- подсчёт начальной суммы и остатка на каждой транзакции
- автоматическое создание контрагентов и их счетов
